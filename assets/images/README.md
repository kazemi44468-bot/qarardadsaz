# تصاویر محلی سایت قراردادساز

تصاویر عکاسی مورد استفاده در صفحات، هنگام اجرای فرایند انتشار GitHub Pages از Unsplash دریافت می‌شوند و در همین پوشه ذخیره می‌شوند. فرایند انتشار فایل‌های JPG را به مخزن اضافه می‌کند تا صفحات از مسیرهای محلی `assets/images/` استفاده کنند و هنگام نمایش سایت به سرویس تصاویر خارجی وابسته نباشند.
