# تصاویر سایت قراردادساز

این پوشه برای تصاویر محلی وب‌سایت در نظر گرفته شده است. صفحات فعلی از تصاویر عکاسی حرفه‌ای Unsplash با نشانی مستقیم استفاده می‌کنند؛ فایل‌های تصویری باینری در این مرحله به مخزن بارگذاری نشده‌اند، بنابراین برای میزبانی کاملاً محلی باید فایل‌های منتخب در همین پوشه قرار گیرند و نشانی تصاویر در صفحات به مسیرهای محلی تغییر کند.
