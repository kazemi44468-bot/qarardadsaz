# پلتفرم هوشمند قراردادساز

وب‌سایت فارسی و راست‌چین معرفی محصول «پلتفرم هوشمند قراردادساز»؛ محصولی از شرکت زیست‌بوم هوشمند فناوری ایرانیان.

## صفحات
- `index.html`: صفحه نخست و معرفی کلی
- `pages/about.html`: تعریف محصول، مأموریت و جایگاه سازمانی
- `pages/process.html`: مراحل ساخت پیش‌نویس
- `pages/capabilities.html`: قابلیت‌ها و اجزای سامانه
- `pages/security.html`: امنیت، حریم خصوصی و حدود مسئولیت
- `pages/roadmap.html`: نقشه راه توسعه
- `pages/relationship.html`: ارتباط قراردادساز با قرارداد فرم و منابع پیش‌نویس
- `pages/contact.html`: مسیرهای ارتباطی موردنیاز
- `404.html`: صفحه خطای GitHub Pages
- `assets/css/style.css`: طراحی یکپارچه و واکنش‌گرا
- `assets/js/main.js`: رفتار منوی موبایل

## انتشار با GitHub Pages
در تنظیمات مخزن، بخش **Pages** را باز کنید و منبع انتشار را روی شاخه `main` و پوشه `/(root)` قرار دهید. سپس نشانی GitHub Pages مخزن را باز کنید.

## نکته درباره وضعیت محصول
این مخزن وب‌سایت معرفی و مستندسازی محصول است؛ موتور تولید قرارداد، ذخیره‌سازی امن، حساب کاربری، پنل‌های عملیاتی، API و تولید فایل هنوز به‌عنوان قابلیت عملیاتی در این وب‌سایت ادعا نشده‌اند. پروژه «قرارداد فرم» نیز محصول مکمل جداگانه‌ای برای آرشیو نمونه‌ها خواهد بود.
